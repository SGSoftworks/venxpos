# Iniciar Sesión — Manual de Usuario

## Requisitos

- Conexión a internet
- Usuario registrado en VenxPos

## Pasos

1. Abrir VenxPos
2. Ingresar **correo electrónico** y **contraseña**
3. Hacer clic en **Iniciar sesión**

## Resultado

- Dashboard principal con indicadores de ventas y caja
- Nombre de sucursal visible en la barra superior
- Si es Admin General, podrá cambiar de sucursal

## Problemas comunes

| Problema | Solución |
|----------|---------|
| "Sin conexión a internet" | Verificar conexión y hacer clic en Reintentar |
| Credenciales incorrectas | Verificar correo y contraseña |
| "No tiene sucursales asignadas" | Contactar al administrador del sistema |
