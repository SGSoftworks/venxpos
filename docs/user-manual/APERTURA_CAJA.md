# Apertura de Caja — Manual de Usuario

## Requisitos

- Sesión iniciada
- Estar en la **sucursal principal** (solo Admin General puede tener múltiples)

## Pasos

1. Al ingresar a Caja, el sistema verifica si hay una apertura activa
2. Si no hay apertura, aparece el modal **Apertura de Turno**
3. Ingresar el **fondo inicial de caja** (monto en pesos)
4. Hacer clic en **Iniciar turno** o presionar Enter

## Resultado

- Turno abierto
- Caja lista para operar
- Se puede empezar a vender

## Notas

- El fondo inicial puede ser $0
- Si está en una sucursal que no es su principal, no podrá abrir caja
- Solo puede existir una apertura activa por sucursal
