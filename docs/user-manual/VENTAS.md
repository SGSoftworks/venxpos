# Ventas — Manual de Usuario

## Buscar productos

Escriba en la barra de búsqueda (mínimo 2 caracteres). Resultados aparecen automáticamente.

## Escanear código de barras

Apunta el lector al código. El producto se agrega automáticamente al carrito. Sonido de confirmación y toast verde. Si no existe, sonido de error y toast rojo.

## Agregar al carrito

Clic en un resultado de búsqueda. Si el producto es por peso, se abre el modal para ingresar kilogramos.

## Venta libre (F9)

Para productos sin código de barras:
1. Presionar F9 o usar menú ⚙
2. Seleccionar categoría
3. Ingresar valor
4. Enter para agregar

## Editar carrito

- **F2**: Cambiar cantidad del ítem seleccionado
- **F3**: Aplicar descuento % o cambiar precio
- **Supr**: Eliminar ítem (requiere PIN admin si no es administrador)
- **↑↓**: Navegar entre ítems

## Pagar (F10)

1. Presionar F10 o clic en "Pagar" en la barra de acciones
2. Seleccionar método: Efectivo, Tarjeta, Billetera, Mixto
3. Ingresar monto recibido (efectivo) o montos (mixto)
4. Clic en **Confirmar Pago**

## Ticket

Después del pago, el ticket se imprime automáticamente. Para reimprimir:
- **F8**: Reimprimir último ticket
- Menú ⚙ → Reimprimir ticket
