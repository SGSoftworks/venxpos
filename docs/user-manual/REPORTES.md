# Reportes — Manual de Usuario

## Acceder

Clic en **Reportes** en la barra superior, o desde el menú ⚙.

## Pestañas

- **Ventas**: subtotal, impuestos, total, transacciones, ticket promedio
- **Métodos**: desglose por método de pago con porcentajes
- **Productos**: productos más/menos vendidos
- **Cierres**: historial de cierres de caja
- **Movimientos**: trazabilidad de inventario

## Filtros de fecha

- **Hoy**: ventas del día actual
- **Semana**: lunes a hoy
- **Mes**: día 1 a hoy
- **Personalizado**: rango de fechas

## Exportar

| Formato | Descripción |
|---------|------------|
| **CSV** | Archivo CSV con datos de la pestaña activa |
| **Excel** | Archivo .xlsx con diálogo para guardar |
| **PDF** | Archivo .pdf con tabla formateada y metadatos |

Al exportar, se abre un diálogo para elegir carpeta y nombre de archivo.
